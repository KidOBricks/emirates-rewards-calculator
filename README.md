# Emirates Skywards Rewards & Miles Calculator ✈️

An interactive, responsive single-page web app to calculate and plan non-flight merchandise redemptions on the **Emirates Official Store** (`emirates.store`) using **Emirates Skywards Miles**.

## ✨ Features
* **Custom Starting Miles:** Defaults to 21,975 miles, but anyone can input their own balance.
* **Curated Official Store Catalog:** Aircraft models (A380, B777, A350), luxury bags, travel gear, and accessories.
* **Interactive Cart:** Real-time points spent, points remaining, and total USD merchandise value.
* **Dynamic Budget Warnings:** Visual indicator and progress bar that alerts when over budget.
* **Destination Shipping Calculator:** Real-time shipping costs and customs guidance for the UK, Netherlands, and India.
* **WhatsApp Share Integration:** "Copy Summary for WhatsApp" button generates a formatted text summary ready to paste into any chat.
* **Zero Dependencies:** Pure vanilla HTML5, CSS3, and modern JavaScript. Works offline and on any device.

## 🚀 How to Host on GitHub Pages (Free & 1-Minute Setup)

### Step 1: Create a New GitHub Repository
1. Go to [GitHub: New Repository](https://github.com/new).
2. Name it (for example: `emirates-rewards-calculator`).
3. Keep it **Public** and leave all checkboxes (README, .gitignore) unchecked.
4. Click **Create repository**.

### Step 2: Push This Code
Run the following commands in this directory:
```bash
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. On your GitHub repository page, click **Settings** (top right tab).
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment > Branch**:
   * Select branch: **`main`**
   * Select folder: **`/ (root)`**
   * Click **Save**.
4. In about 30 seconds, your interactive web app will be live at:
   `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`
